Blogs / Casos de Estudio

Administración y Diseño de Base de Datos (MySQL)

1. Descripción: Proyecto académico enfocado en la estructuración, normalización y administración de una base de datos relacional para gestionar un sistema con múltiples usuarios.

2. Requerimientos del cliente: El sistema debía manejar transacciones seguras, automatizar tareas recurrentes en el servidor y mantener un registro estricto (auditoría) de todos los movimientos y cambios de datos.

3. ¿Cómo se diseñó la solución?: Se esquematizó primero el modelo entidad-relación y se planificó la lógica del negocio para delegarla directamente al motor de la base de datos (evitando sobrecargar el código externo).

4. ¿Cómo se implementó la solución?: Utilizando MySQL, se programaron procedimientos almacenados (Stored Procedures) para las operaciones principales, Triggers para llenar automáticamente las tablas de bitácora y Vistas (Views) para facilitar la generación de reportes.

5. ¿Cuál fue el resultado?: Una base de datos eficiente, automatizada y altamente segura que mantiene la integridad de la información sin importar desde dónde se conecte el programa cliente.

Gestión de Calidad: Caso B (Sistema de Gestión Académica)

1. Descripción: Documentación y aplicación del "Modelo V" para el desarrollo estructurado y validación de un sistema integral de gestión escolar.

2. Requerimientos del cliente: Asegurar que el software final esté libre de errores críticos y garantizar que el sistema cumpla con todos los estándares requeridos antes de su despliegue en la institución.

3. ¿Cómo se diseñó la solución?: Asumiendo el rol de "Persona 3" (Pruebas y Prevención de Riesgos), se trazó una estrategia donde cada fase de diseño del lado izquierdo de la "V" tuviera su respectiva contramedida de validación del lado derecho.

4. ¿Cómo se implementó la solución?: Se elaboró una planeación detallada estructurando casos de prueba específicos (unitarias, de integración y de aceptación) y se documentó un plan de contingencia para posibles riesgos técnicos del sistema.

5. ¿Cuál fue el resultado?: Un marco de aseguramiento de calidad (QA) robusto que previene fallos técnicos, reduciendo costos de mantenimiento y garantizando la estabilidad del sistema académico.
